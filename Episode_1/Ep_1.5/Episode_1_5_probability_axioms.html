2 About the Dataset

2.1 Overview

This document analyzes the Kampala Subnational Dekadal Rainfall Dataset (1981–2026), derived from the United Nations World Food Programme (WFP) Vulnerability Analysis and Mapping (VAM) data engine and the Climate Hazards Group InfraRed Precipitation with Stations (CHIRPS).

2.2 Technical & Geographic Specifications

  • Geographic Unit: Kampala District, Uganda
  • Administrative Hierarchy: Administrative Level 2 (adm_level = 2)
  • UN OCHA Place Code (PCODE): UG1002 (adm_id = 999571)
  • Spatial Grid Resolution: n_pixels = 19 (≈\approx 475 km2km^2 spatial aggregation across 5 km * 5 km satellite cells)

  • Sample Space Dimension (N): 1,650 dekads (36 dekads/year across 45.8 years from January 1981 to October 2026)

4 Variable Selection & Event Masking

From Episode 1.2, we define our sample space (Ω\Omega or S) as all observed Kampala dekads (N=1,650N = 1,650). We set up the following disjoint and non-disjoint events based on rainfall height extracted into a dedicated vector (rfh_mm <- df$rfh):

  • Event AA (Wet Dekad): rfh_mm≥20.0 mm\text{rfh\_mm} \ge 20.0\text{ mm}
  • Event AcA^c (Dry / Low-Rain Dekad): rfh_mm<20.0 mm\text{rfh\_mm} < 20.0\text{ mm}
  • Event BB (Heavy Rain Dekad): rfh_mm≥50.0 mm\text{rfh\_mm} \ge 50.0\text{ mm}
  • Event CC (Moderate Rain Dekad): 20.0 mm≤rfh_mm<50.0 mm20.0\text{ mm} \le \text{rfh\_mm} < 50.0\text{ mm}

5 Computing Empirical Probabilities

NoteR Micro-Hint 3: Logical Averaging with mean() and summarise()

In R, TRUE coerces to 1 and FALSE coerces to 0. Passing a logical vector to mean() calculates ∑TRUEN\frac{\sum \text{TRUE}}{N}, yielding the empirical probability P(E)P(E). summarise() collapses thousands of rows into a single summary table.

6 Programmatic Verification of Kolmogorov’s Axioms

We test whether our empirical estimates satisfy Kolmogorov’s foundational rules derived in Episode 1.2:

  1. Axiom 1 & 2 (Non-negativity & Normalization): 0≤P(E)≤10 \le P(E) \le 1 and P(Ω)=1.0P(\Omega) = 1.0.
  2. Proof 1 — The Complement Rule: P(A)+P(Ac)=1.0P(A) + P(A^c) = 1.0.
  3. Proof 2 — Additivity for Disjoint Sets: Since B∩C=∅B \cap C = \emptyset and A=B∪CA = B \cup C:

P(A)=P(B∪C)=P(B)+P(C)P(A) = P(B \cup C) = P(B) + P(C)

  1. Proof 3 — Monotonicity: Since B⊆AB \subseteq A (Heavy rain is a subset of Wet dekads):

P(B)≤P(A)P(B) \le P(A)

NoteR Micro-Hint 4: Safe Equality Testing with all.equal() and stopifnot()

Floating-point arithmetic can introduce microscopic rounding differences. In R, all.equal(x, y) checks if numbers are equal within machine precision tolerances, while stopifnot() halts script execution if a condition is FALSE (R’s native equivalent of Python’s assert).

7 Sample Space Partition Visualization (ggplot2)

We construct a publication-ready graphic of the sample space partition Ω=1,650 dekads\Omega = 1,650\text{ dekads}. The three disjoint event sets AcA^c (Dry), CC (Moderate), and BB (Heavy) completely cover Ω\Omega without overlap:

Ω=Ac∪C∪B⟹P(Ω)=P(Ac)+P(C)+P(B)=1.0\Omega = A^c \cup C \cup B \quad \implies \quad P(\Omega) = P(A^c) + P(C) + P(B) = 1.0

NoteR Micro-Hint 5: Grammar of Graphics with ggplot2

8 Empirical Insights

An analysis of the Kampala Subnational Dekadal Rainfall Dataset (1981–2026) across N=1,650N = 1,650 dekads yields the following key statistical properties:

  • High Baseline Probability of Rainfall (P(A)=63.09%P(A) = 63.09\%): Over the 45.8-year period, nearly two-thirds of all 10-day dekads in Kampala recorded at least 20.0 mm20.0\text{ mm} of rainfall (nA=1,041 dekadsn_A = 1,041\text{ dekads}).
  • Moderate Rain Dominates the Sample Space (P(C)=45.58%P(C) = 45.58\%): Moderate dekadal rainfall (20.0 mm≤rfh<50.0 mm20.0\text{ mm} \le \text{rfh} < 50.0\text{ mm}) accounts for the largest partition of the sample space (nC=752 dekadsn_C = 752\text{ dekads}), representing standard operational moisture levels.
  • Low Frequency of Heavy Rain / Flood Risk (P(B)=17.52%P(B) = 17.52\%): Dekads with extreme precipitation (rfh≥50.0 mm\text{rfh} \ge 50.0\text{ mm}) occur in less than 1 in 5 dekads (nB=289 dekadsn_B = 289\text{ dekads}), confirming that extreme events occupy a strict subset of total wet dekads.
  • Dry Dekad Occurrence (P(Ac)=36.91%P(A^c) = 36.91\%): Dry dekads (rfh<20.0 mm\text{rfh} < 20.0\text{ mm}) occur in approximately 37% of all observed periods (nAc=609 dekadsn_{A^c} = 609\text{ dekads}), reflecting Kampala’s distinct bimodal dry season windows (January–February and June–July).

9 Mathematical & Methodological Summary

This Quarto document successfully bridges measure-theoretic probability theory with practical R data engineering:

  1. Axiomatic Soundness: Kolmogorov’s three probability axioms hold programmatically across the entire 45.8-year climate record:
  • Normalization: P(Ω)=P(Ac∪C∪B)=36.91%+45.58%+17.52%=100.0%P(\Omega) = P(A^c \cup C \cup B) = 36.91\% + 45.58\% + 17.52\% = 100.0\%.
  • Complement Rule: P(A)+P(Ac)=0.6309+0.3691=1.0000P(A) + P(A^c) = 0.6309 + 0.3691 = 1.0000.
  • Additivity for Disjoint Sets: P(B∪C)=P(B)+P(C)=0.1752+0.4558=0.6309=P(A)P(B \cup C) = P(B) + P(C) = 0.1752 + 0.4558 = 0.6309 = P(A).
  • Monotonicity: P(B)≤P(A)⟹0.1752≤0.6309P(B) \le P(A) \implies 0.1752 \le 0.6309.
  1. Efficiency of Tidy Vectorization: Using dplyr::mutate() combined with mean() provides an execution pattern that avoids slow R for loops when computing empirical probabilities across large vectors.
  2. Reproducible Proofing: Leveraging R’s stopifnot() and all.equal() functions enforces mathematical verification in automated analytical pipelines, preventing bad data or silent errors from passing downstream into policy models.

  )

# Extract scalar probabilities
p_A  <- prob_summary$p_A
p_Ac <- prob_summary$p_Ac

p_C  <- prob_summary$p_C

cat("Empirical Dekadal Probabilities (N = 1,650)\n")

cat(sprintf("P(A^c) [Dry Dekad (<20mm)]:        %.4f  (%.2f%%) | Count: %d\n", p_Ac, p_Ac * 100, prob_summary$n_Ac))

## Programmatic Verification of Kolmogorov's Axioms

We test whether our empirical estimates satisfy Kolmogorov's foundational rules derived in Episode 1.2:

1.  **Axiom 1 & 2 (Non-negativity & Normalization):** $0 \le P(E) \le 1$ and $P(\Omega) = 1.0$.
2.  **Proof 1 — The Complement Rule:** $P(A) + P(A^c) = 1.0$.
3.  **Proof 2 — Additivity for Disjoint Sets:** Since $B \cap C = \emptyset$ and $A = B \cup C$:

$$P(A) = P(B \cup C) = P(B) + P(C)$$

4.  **Proof 3 — Monotonicity:** Since $B \subseteq A$ (Heavy rain is a subset of Wet dekads):

$$P(B) \le P(A)$$

::: {.callout-note title="R Micro-Hint 4: Safe Equality Testing with all.equal() and stopifnot()"}
Floating-point arithmetic can introduce microscopic rounding differences. In R, `all.equal(x, y)` checks if numbers are equal within machine precision tolerances, while `stopifnot()` halts script execution if a condition is `FALSE` (R's native equivalent of Python's `assert`).
:::


```{r}
#| label: verify-axioms

cat("Kolmogorov Axiom Verifications \n\n")

# Verification 1: Complement Rule P(A) + P(A^c) == 1.0
complement_sum <- p_A + p_Ac
cat("1. Complement Rule Check:\n")
cat(sprintf("   P(A) + P(A^c) = %.4f + %.4f = %.4f\n", p_A, p_Ac, complement_sum))
stopifnot(isTRUE(all.equal(complement_sum, 1.0)))
cat("   RESULT: Verified Mathematically (P(A^c) = 1 - P(A))\n\n")

# Verification 2: Additivity for Disjoint Sets P(B U C) == P(B) + P(C) == P(A)
disjoint_sum <- p_B + p_C
cat("2. Disjoint Additivity Check (A = B U C):\n")
cat(sprintf("   P(B) + P(C) = %.4f + %.4f = %.4f | P(A) = %.4f\n", p_B, p_C, disjoint_sum, p_A))
stopifnot(isTRUE(all.equal(disjoint_sum, p_A)))
cat("   RESULT: Verified Mathematically (P(B U C) = P(B) + P(C))\n\n")

# Verification 3: Monotonicity Property (B subset of A => P(B) <= P(A))
cat("3. Monotonicity Check (B subset of A):\n")
cat(sprintf("   P(B) [%.4f] <= P(A) [%.4f] is %s (%.4f <= %.4f)\n", p_B, p_A, p_B <= p_A, p_B, p_A))
stopifnot(p_B <= p_A)
cat("   RESULT: Verified Mathematically (P(B) <= P(A))\n\n")

cat("STATUS: All Kolmogorov Probability Axioms Verified in R!\n")

```

An analysis of the **Kampala Subnational Dekadal Rainfall Dataset (1981–2026)** across $N = 1,650$ dekads yields the following key statistical properties:

- **High Baseline Probability of Rainfall (**$P(A) = 63.09\%$): Over the 45.8-year period, nearly two-thirds of all 10-day dekads in Kampala recorded at least $20.0\text{ mm}$ of rainfall ($n_A = 1,041\text{ dekads}$).
- **Moderate Rain Dominates the Sample Space (**$P(C) = 45.58\%$): Moderate dekadal rainfall ($20.0\text{ mm} \le \text{rfh} < 50.0\text{ mm}$) accounts for the largest partition of the sample space ($n_C = 752\text{ dekads}$), representing standard operational moisture levels.

- **Dry Dekad Occurrence (**$P(A^c) = 36.91\%$): Dry dekads ($\text{rfh} < 20.0\text{ mm}$) occur in approximately 37% of all observed periods ($n_{A^c} = 609\text{ dekads}$), reflecting Kampala's distinct bimodal dry season windows (January–February and June–July).
